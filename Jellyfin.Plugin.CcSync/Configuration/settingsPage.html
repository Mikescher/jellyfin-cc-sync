jClipCorn

Path of the ClipCornDB folder as Jellyfin sees it, e.g. /clipcorn. It holds ClipCornDB.db and ClipCornUserData.db and must be writable.
IANA zone of the local timestamps jClipCorn stores, e.g. Europe/Berlin.
Viewed-history entries without a time count as watched at this local time.
A running jClipCorn refreshes its lock every 60 minutes; jClipCorn itself treats a lock older than 180 minutes as left behind by a crash.
A copy of ClipCornUserData.db is taken before every write.
Uses the values in this form, saved or not. Reads a snapshot copy and creates and deletes one probe file in the directory.

Jellyfin

The one Jellyfin user whose watch state and favourites mirror jClipCorn and whose watches are written back.
